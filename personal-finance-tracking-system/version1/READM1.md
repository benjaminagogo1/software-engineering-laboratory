# Personal Finance Tracking System (Version 1.0)

## Overview

Personal Finance Tracking System is a command-line application developed with Python using Object-Oriented Programming (OOP) principles. It enables users to manage their personal expenses by adding, viewing, searching, updating, and deleting expense records. The application stores data in a JSON file, ensuring that expenses are preserved even after the program is closed.

This project represents **Version 1.0** of an evolving software project that will be progressively enhanced with improved architecture, databases, web technologies, and deployment in future versions.

## Features

* Add a new expense
* View all expenses
* Search for an expense by name
* Update an existing expense
* Delete an expense
* Persistent data storage using JSON
* Input validation and error handling

## Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
* JSON for data persistence

## How to Run

1. Ensure Python 3 is installed.
2. Clone or download the project.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```
